LunaLS
===========

Overview

## Description
This programme changes the driving style according to the sensor value and detects the road surface condition through calculation.
When the machine's wheels are on a flat road, the pressure in the wheels will be high. When it starts climbing stairs, the pressure in the wheel changes.
By taking the pressure value, it can roughly detect whether it is on a flat road or not.
I omit the Motor's program to simplize.

## Requirement
List of Circuit Component
1:Air pressure sensor...MIS-2500-015G
2:Relay module...G5V-1
3:Solenoid valve...VQ31A1-5G-C10

QuickStats(free libraly in Github:https://github.com/dndubins/QuickStats)
